安装 LangGraph

要安装基础的 LangGraph 包：

pip install -U langgraph
uv add langgraph

要使用 LangGraph，您通常需要访问 LLM 并定义工具。您可以按照自己觉得合适的方式来实现。

一种方式（文档中使用的）是使用 LangChain。

安装 LangChain

使用以下命令安装 LangChain：

pip install -U langchain
# 需要 Python 3.10+
uv add langchain
# 需要 Python 3.10+

LLM 提供商

要使用特定的 LLM 提供商包，您需要单独安装它们。

请参阅集成页面了解提供商特定的安装说明。
