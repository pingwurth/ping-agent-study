# 一、数据预处理阶段要解决的问题
1. **文档格式复杂**
   - PDF、Word、图片、扫描件、表格、代码、网页怎么统一提取？
   - 乱码、换行错乱、页眉页脚、水印、目录干扰怎么清洗？

2. **文本分割（核心难点）**
   - 切太大：超出模型上下文、语义模糊、检索不准
   - 切太小：信息碎片化，答非所问
   - 硬切：句子被截断，语义断裂
   → 必须用**递归分割 + 语义分割 + 按标题层级分割**

3. **多语言/混合语言问题**
   - 中英混合、专业术语、公式、代码
   - 分词、embedding 模型不匹配导致检索崩掉

4. **脏数据过滤**
   - 重复内容、无关页面、低质量片段
   - 过长句子、无意义文本、表格乱码

# 二、向量与检索阶段要解决的问题
5. **Embedding 模型选择**
   - 通用模型 vs 垂直领域模型（医疗/法律/金融）
   - 中文效果差异巨大
   - 向量维度、速度、精度权衡

6. **向量库选型与性能**
   - 单机 FAISS / Chroma
   - 生产 Milvus / Qdrant / Weaviate
   - 百万级以上数据如何保证检索速度？

7. **检索不准（最常见痛点）**
   - 关键词匹配不上语义
   - 用户问法和文档写法差异大
   - 同义词、缩写、别称导致召回失败
   → 需要解决：**语义稀疏、领域术语、问句改写**

8. **检索排序问题**
   - 相似度分数不可靠
   - 新旧文档权重、重要性权重
   - 如何把“真正相关”排前面

# 三、Prompt 与大模型生成阶段要解决的问题
9. **上下文窗口管理**
   - 检索回来太多内容，塞不进上下文
   - 塞太少：信息不足
   - 如何**精简、去重、排序、压缩**上下文

10. **幻觉问题（RAG 核心目标）**
    - 模型瞎编、引用不存在内容
    - 解决：强制引用原文、限制生成范围、加校验步骤

11. **多轮对话记忆**
    - 用户追问时，如何关联历史问题
    - 如何避免重复检索、重复上下文

12. **生成质量控制**
    - 答案太简略/太啰嗦
    - 专业术语解释不清
    - 格式混乱（列表、表格、步骤）

# 四、系统工程与稳定性问题
13. **并发与性能**
    - 多人同时查询卡顿
    - 向量检索慢、Embedding 慢
    - 接口超时

14. **增量更新与文档管理**
    - 新增文档怎么增量入库？
    - 删除/修改文档怎么同步？
    - 如何避免重复建库、重复向量

15. **元数据过滤**
    - 按部门、文档类型、时间、权限筛选
    - 不做权限控制 = 生产不可用

16. **监控与评估**
    - 怎么知道 RAG 好不好用？
    - 检索召回率、精确率、命中率
    - 哪些问题答不上来？为什么？

# 五、高级 RAG 必须解决的进阶问题
17. **长文档深度理解**
    - 跨章节知识、总结性问题
    - 普通 RAG 只能搜到局部，答不出来

18. **复杂逻辑推理**
    - 对比、计算、归纳、多文档综合
    - 基础 RAG 做不到

19. **表格、图表、图片理解**
    - 常规 RAG 只支持纯文本
    - 表格需要 Table RAG / LayoutLM

20. **多跳问答（Multi-hop）**
    - 需要查多个文档才能得出答案
    - 基础 RAG 一次检索搞不定

# 六、安全与合规问题
21. **敏感信息泄露**
    - 身份证、电话、隐私内容被检索并输出
    - 需要数据脱敏、权限、白名单

22. **内容安全**
    - 恶意问题诱导输出违规内容
    - 检索结果含敏感内容如何拦截

# 七、用一句话总结：RAG 要解决的核心三件事
1. **把文档处理好**（提取、清洗、分割）
2. **把相关内容精准找出来**（检索、排序、过滤）
3. **让模型只根据找到的内容回答，不瞎编**（prompt、上下文、校验）
