流式传输

提示

对于新应用，推荐使用事件流式传输 — 这是在 LangGraph v1.2 中引入的类型化投影 API。它为每个投影（messages、values、subgraphs、output）提供独立的迭代器，因此你可以独立消费它们。请参阅 事件流式传输。

本页介绍 LangGraph 的 流模式 API，通过 stream（同步）和 astream（异步）方法暴露图执行过程中的流式输出。支持的流模式包括 updates、values、messages、custom、checkpoints、tasks 和 debug。当你需要直接访问图运行时事件或特定流模式输出时使用此 API。

快速开始

基本用法

stream 和 astream 方法以迭代器的形式产出流式输出。你可以传递一个或多个流模式来控制接收的数据类型。

for chunk in graph.stream(
    {"topic": "ice cream"},
    stream_mode=["updates", "custom"],
    version="v2",
):
    if chunk["type"] == "updates":
        for node_name, state in chunk["data"].items():
            print(f"Node {node_name} updated: {state}")
    elif chunk["type"] == "custom":
        print(f"Status: {chunk['data']['status']}")

输出：

Status: thinking of a joke...
Node generate_joke updated: {'joke': 'Why did the ice cream go to school? To get a sundae education!'}
完整示例 
from typing import TypedDict
from langgraph.graph import StateGraph, START, END
from langgraph.config import get_stream_writer

class State(TypedDict):
    topic: str
    joke: str

# 使用 get_stream_writer 发出自定义状态
def generate_joke(state: State):
    writer = get_stream_writer()
    writer({"status": "thinking of a joke..."})
    return {"joke": f"Why did the {state['topic']} go to school? To get a sundae education!"}

graph = (
    StateGraph(State)
    .add_node(generate_joke)
    .add_edge(START, "generate_joke")
    .add_edge("generate_joke", END)
    .compile()
)

for chunk in graph.stream(
    {"topic": "ice cream"},
    stream_mode=["updates", "custom"],
    version="v2",
):
    if chunk["type"] == "updates":
        for node_name, state in chunk["data"].items():
            print(f"Node {node_name} updated: {state}")
    elif chunk["type"] == "custom":
        print(f"Status: {chunk['data']['status']}")
提示

如果你在调试流式事件、逐 token 检查 LLM 输出或监控延迟方面需要帮助，请查看 LangSmith。请参阅 LangSmith 追踪快速入门。

流式输出格式（v2）

注意

需要 LangGraph >= 1.1。本页所有示例均使用 version="v2"。

传递 version="v2" 可获得统一的输出格式。每个 chunk 都是一个具有统一结构的 StreamPart 字典：

{
    "type": "values" | "updates" | "messages" | "custom" | "checkpoints" | "tasks" | "debug",
    "ns": (),           # 命名空间元组，子图事件时填充
    "data": ...,        # 实际负载（类型因流模式而异）
}

每种流模式都有对应的 TypedDict：ValuesStreamPart、UpdatesStreamPart、MessagesStreamPart、CustomStreamPart、CheckpointStreamPart、TasksStreamPart、DebugStreamPart。这些类型可从 langgraph.types 导入。联合类型 StreamPart 是基于 part["type"] 的不相交联合，支持类型缩窄。

v2 与 v1 对比：

  • v2： chunk["type"]、chunk["ns"]、chunk["data"] 始终存在
  • v1： 单模式返回原始数据；多模式返回 (mode, data) 元组；子图返回 (namespace, data) 元组
# v2 示例
for chunk in graph.stream(inputs, stream_mode="updates", version="v2"):
    print(chunk["type"])  # "updates"
    print(chunk["ns"])    # ()
    print(chunk["data"])  # {"node_name": {"key": "value"}}
# v1 示例
for chunk in graph.stream(inputs, stream_mode="updates"):
    print(chunk)  # {"node_name": {"key": "value"}}

类型缩窄示例：

for chunk in graph.stream(inputs, stream_mode=["values", "updates", "messages", "custom"], version="v2"):
    if chunk["type"] == "values":
        print(chunk["data"])       # 完整状态
    elif chunk["type"] == "updates":
        print(chunk["data"])       # 状态更新
    elif chunk["type"] == "messages":
        print(chunk["data"])       # (消息块, 元数据)
    elif chunk["type"] == "custom":
        print(chunk["data"])       # 自定义数据

流模式

将一个或多个流模式作为列表传递给 stream 或 astream。

模式 类型 描述
values ValuesStreamPart 每步执行后的完整状态
updates UpdatesStreamPart 每步执行后的状态更新；同一步骤中的多个更新分别流式传输
messages MessagesStreamPart 来自 LLM 调用的 (LLM token, 元数据) 二元组
custom CustomStreamPart 通过 get_stream_writer 从节点发出的自定义数据
checkpoints CheckpointStreamPart 检查点事件（与 get_state() 格式相同）；需要检查点存储器
tasks TasksStreamPart 任务开始/完成事件，包含结果和错误；需要检查点存储器
debug DebugStreamPart 所有可用信息 — 结合了 checkpoints 和 tasks 并附带额外元数据

图状态

使用 updates 和 values 流模式来流式传输图状态。updates 流式传输每步的状态更新；values 流式传输每步的完整状态值。

以下示例共用的图定义代码：

from typing import TypedDict
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    topic: str
    joke: str

def refine_topic(state: State):
    return {"topic": state["topic"] + " and cats"}

def generate_joke(state: State):
    return {"joke": f"This is a joke about {state['topic']}"}

graph = (
    StateGraph(State)
    .add_node(refine_topic)
    .add_node(generate_joke)
    .add_edge(START, "refine_topic")
    .add_edge("refine_topic", "generate_joke")
    .add_edge("generate_joke", END)
    .compile()
)
for chunk in graph.stream(
    {"topic": "ice cream"},
    stream_mode="updates",
    version="v2",
):
    if chunk["type"] == "updates":
        for node_name, state in chunk["data"].items():
            print(f"Node `{node_name}` updated: {state}")

输出：

Node `refine_topic` updated: {'topic': 'ice cream and cats'}
Node `generate_joke` updated: {'joke': 'This is a joke about ice cream and cats'}
for chunk in graph.stream(
    {"topic": "ice cream"},
    stream_mode="values",
    version="v2",
):
    if chunk["type"] == "values":
        print(f"topic: {chunk['data']['topic']}, joke: {chunk['data']['joke']}")

输出：

topic: ice cream, joke:
topic: ice cream and cats, joke:
topic: ice cream and cats, joke: This is a joke about ice cream and cats

LLM Token

messages 流模式可以从图中的任何部分（包括节点、工具、子图或任务）逐 token 流式传输 LLM 输出。

输出为 (message_chunk, metadata) 元组，其中 message_chunk 是 token/消息段，metadata 是包含图节点和 LLM 调用详情的字典。

注意

如果 LLM 不是 LangChain 集成，请改用 custom 模式（参见与任意 LLM 配合使用）。

警告

在 Python < 3.11 的异步代码中，你必须显式传递 RunnableConfig 给 ainvoke() 以启用正确的流式传输。参见异步 Python < 3.11 章节。

from dataclasses import dataclass
from langchain.chat_models import init_chat_model
from langgraph.graph import StateGraph, START

@dataclass
class MyState:
    topic: str
    joke: str = ""

model = init_chat_model(model="gpt-5.4-mini")

def call_model(state: MyState):
    # 调用 LLM 生成笑话
    model_response = model.invoke(
        [{"role": "user", "content": f"Generate a joke about {state.topic}"}]
    )
    return {"joke": model_response.content}

graph = (
    StateGraph(MyState)
    .add_node(call_model)
    .add_edge(START, "call_model")
    .compile()
)

for chunk in graph.stream(
    {"topic": "ice cream"},
    stream_mode="messages",
    version="v2",
):
    if chunk["type"] == "messages":
        message_chunk, metadata = chunk["data"]
        if message_chunk.content:
            print(message_chunk.content, end="|", flush=True)

from typing import TypedDict
from langchain.chat_models import init_chat_model
from langgraph.graph import StateGraph, START, END

class State(TypedDict):

    joke: str
    poem: str

# 为每个模型分别设置标签

poem_model = init_chat_model(model="gpt-5.4-mini", tags=["poem"])

async def call_model(state: State):
    # 注意：在 Python < 3.11 中，需要显式传递 config
    joke_response = await joke_model.ainvoke(
        [{"role": "user", "content": f"Write a joke about {state['topic']}"}]
    )
    poem_response = await poem_model.ainvoke(
        [{"role": "user", "content": f"Write a poem about {state['topic']}"}]
    )
    return {"joke": joke_response.content, "poem": poem_response.content}

graph = (
    StateGraph(State)
    .add_node(call_model)
    .add_edge(START, "call_model")
    .add_edge("call_model", END)
    .compile()
)

async for chunk in graph.astream(
    {"topic": "cats"},
    stream_mode="messages",
    version="v2",
):
    if chunk["type"] == "messages":
        msg, metadata = chunk["data"]
        # 只打印来自 "joke" 模型的 token
        if metadata["tags"] == ["joke"]:
            print(msg.content, end="|", flush=True)

从流中排除消息

使用 nostream 标签可以将 LLM 输出从流中排除。标记为 nostream 的调用仍然会运行，但不会产出 token。这在 LLM 输出需要用于内部处理（如结构化输出）但不应流式传输到客户端时非常有用，或者当你通过不同通道流式传输相同内容时也可以使用。

from typing import Any, TypedDict
from langchain_anthropic import ChatAnthropic
from langgraph.graph import START, StateGraph

# 正常流式传输的模型
stream_model = ChatAnthropic(model_name="claude-haiku-4-5-20251001")
# 内部模型：通过 nostream 标签从流中排除
internal_model = ChatAnthropic(model_name="claude-haiku-4-5-20251001").with_config(
    {"tags": ["nostream"]}
)

class State(TypedDict):
    topic: str
    answer: str
    notes: str

def answer(state: State) -> dict[str, Any]:
    r = stream_model.invoke(
        [{"role": "user", "content": f"Reply briefly about {state['topic']}"}]
    )
    return {"answer": r.content}

def internal_notes(state: State) -> dict[str, Any]:
    r = internal_model.invoke(
        [{"role": "user", "content": f"Private notes on {state['topic']}"}]
    )
    return {"notes": r.content}

graph = (
    StateGraph(State)
    .add_node("write_answer", answer)
    .add_node("internal_notes", internal_notes)
    .add_edge(START, "write_answer")
    .add_edge("write_answer", "internal_notes")
    .compile()
)

initial_state: State = {"topic": "AI", "answer": "", "notes": ""}
stream = graph.stream_events(initial_state, version="v3")

自定义数据

要从节点或工具发送自定义用户定义数据：

  1. 使用 get_stream_writer 获取流写入器并发出自定义数据。
  2. 设置 stream_mode="custom"（或将其包含在列表中）。
警告

在 Python < 3.11 的异步代码中，get_stream_writer 将无法工作。请改为在你的节点/工具中添加 writer 参数并手动传递。参见异步 Python < 3.11 章节。

from typing import TypedDict
from langgraph.config import get_stream_writer
from langgraph.graph import StateGraph, START

class State(TypedDict):
    query: str
    answer: str

def node(state: State):

graph = (
    StateGraph(State)
    .add_node(node)
    .add_edge(START, "node")
    .compile()
)

inputs = {"query": "example"}

for chunk in graph.stream(inputs, stream_mode="custom", version="v2"):
    if chunk["type"] == "custom":
        print(f"Custom event: {chunk['data']['custom_key']}")

子图输出

在 .stream() 中设置 subgraphs=True 以包含子图输出。输出以 (namespace, data) 元组形式返回，其中 namespace 是路径元组。

for chunk in graph.stream(
    {"foo": "foo"},
    subgraphs=True,
    stream_mode="updates",
    version="v2",
):
    print(chunk["type"])  # "updates"
    print(chunk["ns"])    # () 表示根图, ("node_name:",) 表示子图
    print(chunk["data"])  # {"node_name": {"key": "value"}}
for chunk in graph.stream(
    {"foo": "foo"},
    subgraphs=True,
    stream_mode="updates",
):
    print(chunk)
扩展示例：从子图流式传输 
from typing import TypedDict
from langgraph.graph import StateGraph, START, END

# 子图状态
class SubgraphState(TypedDict):
    foo: str
    bar: str

def sub_node_1(state: SubgraphState):
    return {"bar": state["foo"] + "bar"}

def sub_node_2(state: SubgraphState):
    return {"foo": state["bar"] + "baz"}

subgraph = (
    StateGraph(SubgraphState)
    .add_node(sub_node_1)
    .add_node(sub_node_2)
    .add_edge(START, "sub_node_1")
    .add_edge("sub_node_1", "sub_node_2")
    .add_edge("sub_node_2", END)
    .compile()
)

# 父图状态
class ParentState(TypedDict):
    foo: str
    result: str

def node_1(state: ParentState):
    return {"foo": state["foo"] + "updated"}

def node_2(state: ParentState):
    # 调用子图
    sub_result = subgraph.invoke({"foo": state["foo"]})
    return {"result": sub_result["foo"]}

graph = (
    StateGraph(ParentState)
    .add_node(node_1)
    .add_node(node_2)
    .add_edge(START, "node_1")
    .add_edge("node_1", "node_2")
    .add_edge("node_2", END)
    .compile()
)

# 使用 subgraphs=True 流式传输，包含子图输出
for chunk in graph.stream(
    {"foo": "foo"},
    subgraphs=True,
    stream_mode="updates",
    version="v2",
):
    print(f"type: {chunk['type']}, ns: {chunk['ns']}, data: {chunk['data']}")

import operator
from typing import TypedDict
from openai import AsyncOpenAI
from langchain_core.messages import AIMessage
from langgraph.config import get_stream_writer
from langgraph.graph import StateGraph, START, END

# 使用原始 OpenAI 客户端（非 LangChain 集成）
openai_client = AsyncOpenAI()

async def stream_tokens(prompt: str):
    """异步生成器：逐 token 流式传输 OpenAI 响应"""
    stream = await openai_client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": prompt}],
        stream=True,
    )
    async for event in stream:
        if event.choices[0].delta.content:
            yield event.choices[0].delta.content

from langchain.tools import tool

@tool
async def get_items(place: str) -> str:
    """获取指定地点的物品列表"""
    writer = get_stream_writer()
    full_response = ""
    async for chunk in stream_tokens(f"List items in {place}"):
        writer({"content": chunk})
        full_response += chunk
    return full_response

)
from langchain_openai import ChatOpenAI

model = ChatOpenAI(model="gpt-5.5", streaming=False)
注意

并非所有集成都支持 streaming 参数。如果你的模型不支持它，请改用 disable_streaming=True — 该选项通过基类在所有聊天模型上可用。

迁移到 v2

场景 v1（默认） v2（version="v2"）
单流模式 原始数据（dict） StreamPart 字典，包含 type、ns、data
多流模式 (mode, data) 元组 相同的 StreamPart 字典，通过 chunk["type"] 过滤
子图流式传输 (namespace, data) 元组 相同的 StreamPart 字典，检查 chunk["ns"]
多模式 + 子图 (namespace, mode, data) 三元组 相同的 StreamPart 字典
invoke() 返回类型 普通 dict（状态） GraphOutput，包含 .value 和 .interrupts
中断位置（流） 状态字典中的 __interrupt__ 键 values 流式部件上的 interrupts 字段
中断位置（invoke） 结果字典中的 __interrupt__ 键 GraphOutput 上的 .interrupts 属性
Pydantic/dataclass 输出 返回普通 dict 强制转换为 model/dataclass 实例

v2 invoke 格式

from langgraph.types import GraphOutput

result = graph.invoke(inputs, version="v2")

assert isinstance(result, GraphOutput)
result.value       # 你的输出 — dict、Pydantic model 或 dataclass
result.interrupts  # tuple[Interrupt, ...]，如果没有发生中断则为空

当使用除 "values" 之外的任何流模式时，invoke(..., stream_mode="updates", version="v2") 返回 list[StreamPart] 而不是 list[tuple]。

警告

对 GraphOutput 的字典式访问（result["key"]、"key" in result、result["__interrupt__"]）已弃用，将在未来版本中移除。

代码对比 — 中断处理：

config = {"configurable": {"thread_id": "thread-1"}}
result = graph.invoke(inputs, config=config, version="v2")

if result.interrupts:
    print(result.interrupts[0].value)
    graph.invoke(Command(resume=True), config=config, version="v2")
config = {"configurable": {"thread_id": "thread-1"}}
result = graph.invoke(inputs, config=config)

if "__interrupt__" in result:
    print(result["__interrupt__"][0].value)
    graph.invoke(Command(resume=True), config=config)

Pydantic 和 Dataclass 状态强制转换

使用 v2 时，values 模式会自动将输出强制转换为正确的类型：

from pydantic import BaseModel
from typing import Annotated
import operator

class MyState(BaseModel):
    value: str
    items: Annotated[list[str], operator.add]

for chunk in graph.stream(
    {"value": "x", "items": []}, stream_mode="values", version="v2"
):
    print(type(chunk["data"]))  # <class 'MyState'>

异步 Python < 3.11

在 Python < 3.11 中，asyncio 任务不支持 context 参数。这会影响两件事：

  1. 你必须显式将 RunnableConfig 传递到异步 LLM 调用中 — 回调不会自动传播。
  2. 你不能在异步节点/工具中使用 get_stream_writer — 请直接传递 writer 参数。
异步 LLM 调用手动传递 config 
from typing import TypedDict
from langgraph.graph import START, StateGraph
from langchain.chat_models import init_chat_model

model = init_chat_model(model="gpt-5.4-mini")

class State(TypedDict):
    topic: str
    joke: str

async def call_model(state, config):
    topic = state["topic"]
    # 在 Python < 3.11 中，必须显式传递 config
    joke_response = await model.ainvoke(
        [{"role": "user", "content": f"Write a joke about {topic}"}],
        config,
    )
    return {"joke": joke_response.content}

graph = (
    StateGraph(State)
    .add_node(call_model)
    .add_edge(START, "call_model")
    .compile()
)

async for chunk in graph.astream(
    {"topic": "ice cream"},
    stream_mode="messages",
    version="v2",
):
    if chunk["type"] == "messages":
        message_chunk, metadata = chunk["data"]
        if message_chunk.content:
            print(message_chunk.content, end="|", flush=True)
异步自定义流式传输（使用 StreamWriter） 
from typing import TypedDict
from langgraph.types import StreamWriter
from langgraph.graph import StateGraph, START, END

class State(TypedDict):
    topic: str
    joke: str

async def generate_joke(state: State, writer: StreamWriter):
    # 在 Python < 3.11 中，通过参数手动传递 writer
    writer({"custom_key": "Streaming custom data while generating a joke"})
    return {"joke": f"This is a joke about {state['topic']}"}

graph = (
    StateGraph(State)
    .add_node(generate_joke)
    .add_edge(START, "generate_joke")
    .add_edge("generate_joke", END)
    .compile()
)

async for chunk in graph.astream(
    {"topic": "ice cream"},
    stream_mode="custom",
    version="v2",
):
    if chunk["type"] == "custom":
        print(chunk["data"])
