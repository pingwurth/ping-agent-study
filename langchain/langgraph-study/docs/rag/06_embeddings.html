嵌入模型集成

使用 LangChain Python 与嵌入模型集成。

本概览涵盖基于文本的嵌入模型。LangChain 目前不支持多模态嵌入。

嵌入模型将原始文本（如句子、段落或推文）转换为捕获其语义含义的固定长度数值向量。这些向量允许机器基于含义而非精确词汇来比较和搜索文本。

工作原理

  1. 向量化 — 模型将每个输入字符串编码为高维向量。
  2. 相似性评分 — 使用数学指标比较向量，以衡量底层文本的相关程度。

常用相似性指标：

  • 余弦相似度 — 衡量两个向量之间的角度
  • 欧几里得距离 — 衡量点之间的直线距离
  • 点积 — 衡量一个向量在另一个向量上的投影
Python余弦相似度计算
import numpy as np

def cosine_similarity(vec1, vec2):
    dot = np.dot(vec1, vec2)
    return dot / (np.linalg.norm(vec1) * np.linalg.norm(vec2))

similarity = cosine_similarity(query_embedding, document_embedding)
print("余弦相似度:", similarity)

接口

LangChain 为文本嵌入模型提供标准接口。两个主要方法：

  • embed_documents(texts: List[str]) → List[List[float]]：嵌入文档列表
  • embed_query(text: str) → List[float]：嵌入单个查询

常见部署模式

☁️ 托管旗舰版

OpenAI text-embedding-3-large、Cohere embed-english-v3、Google gemini-embedding-001。一次 API 调用，开箱即用的最佳质量。

🏠 本地开源

BAAI/bge-*、sentence-transformers/all-*。下载一次，随处运行。无调用成本，数据永不离开环境。

🎯 专业微调

针对特定领域、语言或任务的微调模型。通常在该领域的检索准确性上超越托管旗舰版。

🚀 生产规模自托管

通过 TEI 或 Ollama 服务的开源模型。提供本地推理的经济效益和托管提供商的水平扩展能力。

选择因素

质量

从 MTEB 排行榜开始。MTEB 跨检索、聚类、分类和重排序任务对嵌入模型进行基准测试，是事实上的行业参考。

成本

托管嵌入通常定价在每百万 token 几美分到约 0.15 美元之间。本地推理无调用成本，但需要 CPU（慢）或 GPU（资本或云成本）。

延迟

托管嵌入 API 每个请求增加约 50-200ms 网络延迟。CPU 上的本地模型对短查询需要 10-100ms。GPU 上，本地推理通常比托管 API 的往返更快。

维度

嵌入维度影响向量存储和查询计算。典型大小：

  • 384（小型 Sentence Transformers 模型）
  • 768（中型 ST 模型）
  • 1024（bge-large、Cohere v3、Voyage）
  • 1536（OpenAI text-embedding-3-small）
  • 3072+（OpenAI text-embedding-3-large）

缓存

嵌入可以存储或临时缓存以避免重新计算。使用 CacheBackedEmbeddings 包装器将嵌入存储在键值存储中。

Python嵌入缓存
from langchain_classic.embeddings import CacheBackedEmbeddings
from langchain_classic.storage import LocalFileStore
from langchain_core.vectorstores import InMemoryVectorStore

underlying_embeddings = ...  # 例如 OpenAIEmbeddings()
store = LocalFileStore("./cache/")

cached_embedder = CacheBackedEmbeddings.from_bytes_store(
    underlying_embeddings, store, namespace=underlying_embeddings.model
)

# 第一次调用
print(cached_embedder.embed_query("Hello, world!"))

# 后续调用使用缓存
print(cached_embedder.embed_query("Hello, world!"))
