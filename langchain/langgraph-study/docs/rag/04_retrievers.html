检索器集成

使用 LangChain Python 与检索器集成。

检索器是给定非结构化查询返回文档的接口。它比向量存储更通用。检索器不需要能够存储文档，只需要能够返回（或检索）它们。检索器可以从向量存储创建，但也足够广泛以包含其他来源。

检索器接受字符串查询作为输入，并返回 Document 对象列表作为输出。

所有向量存储都可以转换为检索器。请参阅向量存储集成文档了解可用的向量存储。此页面列出了通过子类化 BaseRetriever 实现的自定义检索器。

所有检索器

LangChain 支持多种检索器集成，包括：

☁️ 云服务检索器

AWS Bedrock、Google Vertex AI、Elasticsearch Cloud 等托管服务。

🏠 自托管检索器

Elasticsearch、NVIDIA RAG、Graph RAG 等本地部署方案。

🌐 互联网搜索

Parallel、Perplexity、You.com 等实时搜索 API。

🔄 重排序器

Cohere、Pinecone、Contextual AI 等结果重排序服务。

所有向量存储都可以用作检索器。如果您需要简单的相似性搜索，请考虑使用向量存储而不是自定义检索器。
