评估 RAG 应用

检索增强生成 (RAG) 是一种通过提供相关外部知识来增强 LLM 的技术。本教程展示如何使用 LangSmith 评估 RAG 应用。

本教程展示如何使用 LangSmith 评估 RAG 应用：

  1. 如何创建测试数据集
  2. 如何在这些数据集上运行 RAG 应用
  3. 如何使用不同的评估指标衡量应用性能

构建应用

使用三个阶段构建最小 RAG 应用：

  • 索引：将博客文章分块并索引到向量存储中
  • 检索：为用户问题检索相关块
  • 生成：将问题和检索到的文档传递给 LLM

索引文档

Python文档索引
import bs4
import requests
from langchain_core.documents import Document
from langchain_core.vectorstores import InMemoryVectorStore
from langchain_openai import OpenAIEmbeddings
from langchain_text_splitters import RecursiveCharacterTextSplitter

def load_web_page(url: str) -> list[Document]:
    response = requests.get(url)
    response.raise_for_status()
    soup = bs4.BeautifulSoup(response.text, "html.parser")
    return [Document(page_content=soup.get_text(), metadata={"source": url})]

urls = [
    "https://lilianweng.github.io/posts/2023-06-23-agent/",
    "https://lilianweng.github.io/posts/2023-03-15-prompt-engineering/",
    "https://lilianweng.github.io/posts/2023-10-25-adv-attack-llm/",
]

docs_list = [doc for url in urls for doc in load_web_page(url)]

text_splitter = RecursiveCharacterTextSplitter.from_tiktoken_encoder(
    chunk_size=250, chunk_overlap=0
)
doc_splits = text_splitter.split_documents(docs_list)

vectorstore = InMemoryVectorStore.from_documents(
    documents=doc_splits, embedding=OpenAIEmbeddings()
)
retriever = vectorstore.as_retriever(k=6)

生成答案

PythonRAG 机器人
from langchain_openai import ChatOpenAI
from langsmith import traceable

llm = ChatOpenAI(model="gpt-5.5", temperature=1)

@traceable()
def rag_bot(question: str) -> dict:
    docs = retriever.invoke(question)
    docs_string = "".join(doc.page_content for doc in docs)
    instructions = f"""你是一个善于分析源信息并回答问题的助手。
使用以下源文档回答用户的问题。
如果不知道答案，就说不知道。
最多使用三句话，保持答案简洁。


{docs_string}
"""
    ai_msg = llm.invoke([
        {"role": "system", "content": instructions},
        {"role": "user", "content": question},
    ])
    return {"answer": ai_msg.content, "documents": docs}

创建数据集

创建一个小型数据集，包含示例问题和参考答案来评估应用：

Python创建评估数据集
from langsmith import Client

client = Client()

examples = [
    {
        "inputs": {"question": "ReAct 代理如何使用自我反思？"},
        "outputs": {"answer": "ReAct 集成推理和行动，执行动作（如维基百科搜索 API），然后观察/推理工具输出。"},
    },
    {
        "inputs": {"question": "少样本提示可能产生哪些类型的偏见？"},
        "outputs": {"answer": "少样本提示可能产生的偏见包括：(1) 多数标签偏见，(2) 近因偏见，(3) 常见 token 偏见。"},
    },
    {
        "inputs": {"question": "五种对抗性攻击是什么？"},
        "outputs": {"answer": "五种对抗性攻击是：(1) Token 操纵，(2) 基于梯度的攻击，(3) 越狱提示，(4) 人类红队测试，(5) 模型红队测试。"},
    },
]

dataset_name = "Lilian Weng 博客问答"
dataset = client.create_dataset(dataset_name=dataset_name)
client.create_examples(dataset_id=dataset.id, examples=examples)

评估器

LangSmith 提供多种评估器来衡量 RAG 应用的性能：

📝 答案正确性

衡量生成的答案与参考答案的匹配程度。

🎯 答案相关性

衡量答案与问题的相关程度。

📚 基于文档

衡量答案是否基于检索到的文档。

🔍 检索质量

衡量检索到的文档与问题的相关性。

运行评估

Python运行评估
from langsmith.evaluation import evaluate

def target(inputs: dict) -> dict:
    return rag_bot(inputs["question"])

experiment_results = evaluate(
    target,
    data=dataset_name,
    evaluators=[correctness_evaluator, relevance_evaluator, groundedness_evaluator],
    experiment_prefix="rag-eval",
    metadata={"version": "v1"},
)
