LangGraph 概述

通过 LangGraph 获得控制力，设计能够可靠处理复杂任务的智能体

LangGraph 受到众多塑造智能体未来的公司信赖——包括 Klarna、Uber、摩根大通等——它是一个低层级的编排框架和运行时，用于构建、管理和部署长时间运行的有状态智能体。LangGraph 为您提供"细粒度的控制能力，将确定性的手写步骤与 LLM 驱动的智能体步骤混合在同一个图中"，从而打造适合您应用需求的定制化智能体。

LangGraph 是一个非常底层的框架，完全专注于智能体编排。在使用 LangGraph 之前，我们建议您先熟悉构建智能体所用的一些组件，从模型和工具开始。

我们在文档中通常会使用 LangChain 组件来集成模型和工具，但使用 LangGraph 并不强制要求使用 LangChain。如果您刚接触智能体，或者需要更高层级的抽象，我们建议您使用 LangChain 的智能体，它为常见的 LLM 和工具调用循环提供了预构建的架构。

LangGraph 专注于对智能体编排至关重要的底层能力：持久化执行、流式传输、人机协作等。

LangGraph 的核心优势之一是能够在单个图中混合确定性步骤与 LLM 驱动的智能体步骤。这让您可以构建定制化的工作流，其中部分逻辑完全可预测和可审计，而其他部分则灵活且由模型驱动，从而对 AI 的应用位置和方式拥有精确的控制。

LangChain 产品如何协同工作
  • Deep Agents 是一个智能体框架：在 LangGraph 之上提供规划、子智能体、文件系统工具和上下文管理。
  • LangChain 是智能体框架：提供模型、工具和智能体循环的抽象与集成。
  • LangGraph 是编排运行时：提供持久化执行、流式传输、人机协作和持久化存储。
  • LangSmith 是一个平台，提供跨框架的追踪、评估、提示词管理和部署功能。
  • LangSmith Engine 能检测 LangGraph 智能体追踪中的问题并提出修复建议。您可以直接从 Engine 标签页打开包含修复建议的 Pull Request。
  • LangSmith Fleet 是一个无代码智能体构建器，支持模板、集成和常规自动化。

阅读框架、运行时与框架对比了解开源技术栈的比较。

安装

pip

pip install -U langgraph

uv

uv add langgraph

然后，创建一个简单的 Hello World 示例：

from langgraph.graph import StateGraph, MessagesState, START, END

def mock_llm(state: MessagesState):
    return {"messages": [{"role": "ai", "content": "你好，世界"}]}

graph = StateGraph(MessagesState)
graph.add_node(mock_llm)
graph.add_edge(START, "mock_llm")
graph.add_edge("mock_llm", END)
graph = graph.compile()

graph.invoke({"messages": [{"role": "user", "content": "你好！"}]})

提示：使用 LangSmith 来追踪请求、调试智能体行为和评估输出。设置 LANGSMITH_TRACING=true 并配置您的 API 密钥即可开始。按照追踪快速入门进行设置。我们还建议您设置 LangSmith Engine，它可以监控您的追踪、检测问题并提出修复建议。

核心优势

LangGraph 为任何长时间运行的有状态工作流或智能体提供低层级的基础支撑。LangGraph 不会抽象提示词或架构，并提供以下核心优势：

  • 混合确定性与智能体步骤：在单个图中将手写的确定性逻辑与 LLM 驱动的决策相结合。在需要可靠性和可预测性的地方使用确定性步骤，在需要灵活性的地方使用智能体步骤——让您精确控制智能体行为的每个部分。
  • 持久化：构建能够在故障后持久化并可长时间运行的智能体，从中断处恢复执行。
  • 人机协作：通过在任意节点检查和修改智能体状态，融入人工监督。
  • 全面的记忆能力：创建具有短期工作记忆（用于当前推理）和长期跨会话记忆的有状态智能体。
  • 使用 LangSmith 调试：通过可视化工具深入洞察复杂智能体行为，追踪执行路径、捕获状态转换并提供详细的运行时指标。
  • 生产就绪的部署：使用专为处理有状态长时间运行工作流的独特挑战而设计的可扩展基础设施，自信地部署复杂的智能体系统。
